Typing Speed Tester ⌨️

-A Python-based terminal typing speed test game that measures a user’s typing speed and accuracy.
This project was built to practice Python fundamentals, file handling, functions, loops, and user interaction.

Features 🚀
- Multiple difficulty levels
- Random typing paragraphs
- Countdown before test starts
- WPM (Words Per Minute) calculation
- Accuracy checking
- Leaderboard system
- Score saving using text files
- Colored terminal interface using Colorama

---

Technologies Used 🛠️
- Python
- Colorama


How It Works ⚡
- User enters a username
- Selects a difficulty level
- Types the displayed sentence
- Program calculates:
- Typing Speed (WPM)
- Accuracy
- Time Taken
- Scores are saved and displayed in the leaderboard
